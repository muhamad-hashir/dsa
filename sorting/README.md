# Sorting

This folder records my practice with sorting algorithms in C++.

## What I learned

- How bubble sort moves values into the correct order by swapping nearby elements.
- How insertion sort places each new value into its correct position.
- How selection sort finds the smallest value and places it at the front.
- How to sort arrays in ascending and descending order.
- How to write sorting functions and use them with arrays.
- How to use fixed-size arrays and dynamic arrays with `new` and `delete[]`.
- How to create arrays with random values.
- How to copy arrays before testing different algorithms.
- How to measure and compare the running time of sorting algorithms.
- How to use a class for bubble sort with private data, functions, a constructor, and a destructor.

## Files and tasks

- `bubble-sorting.cpp`: Basic bubble sort using an array of five integers.
- `bubble-sorting-oop.cpp`: Bubble sort written as a C++ class.
- `insertion-sorting.cpp`: Basic insertion sort using an array of five integers.
- `selection-sorting.cpp`: Basic selection sort using an array of five integers.
- `task1.cpp`: Bubble sort for user input, in descending order.
- `task2.cpp`: Insertion sort for user input, in descending order.
- `task3.cpp`: Creates and displays an array of random values.
- `task4.cpp`: Creates a random array and applies bubble sort and insertion sort.
- `task5.cpp`: Measures the time taken by bubble sort and insertion sort for different array sizes.

## My DSA journey in this folder

I started by learning how common sorting algorithms work on small arrays. Then I made the algorithms reusable by putting them in functions. After that, I worked with dynamic memory and random arrays. I also practiced sorting in both directions and compared two algorithms using time measurements. Finally, I used object-oriented programming to organize bubble sort inside a class.

This folder helped me understand arrays, loops, comparisons, swapping, memory management, functions, classes, and algorithm performance.
