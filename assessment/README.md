
# DSA Assessment

This folder contains our **mid-prep assessment** for Data Structures and Algorithms.

## What We Did

- Used arrays and pointers to find the second largest value.
- Built a stack using an array.
- Built a queue using an array.
- Implemented a priority queue for student advising, ordered by CGPA and student ID.
- Practiced singly linked lists with student records.
- Inserted and searched product records by category using a singly linked list.
- Practiced doubly linked lists with student records.
- Implemented a product queue using a doubly linked list.
- Added, removed, searched, and updated list items.
- Found the highest and lowest GPA in a student list.
- Practiced insertion sort.
- Practiced selection sort.
- Handled empty and full stack or queue cases.

## Main Topics

- Arrays
- Pointers
- Stacks
- Queues
- Priority queues
- Singly linked lists
- Doubly linked lists
- Student and product records
- Searching
- Sorting

These programs help us prepare for the next part of our DSA course.
