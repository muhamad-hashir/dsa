# Lab 3: Stacks

This lab was completed as part of the DSA journey to understand the **LIFO (Last In, First Out)** principle and implement stack-based solutions in C++.

## Tasks

- **Task 1:** Implemented a stack using an array with push, pop, peek, empty, full, and display operations.
- **Task 2:** Created an interactive menu-driven stack program for performing common stack operations.
- **Task 3:** Used a stack to reverse a string by pushing and popping its characters.
- **Task 4:** Checked whether parentheses, braces, and brackets in an expression are balanced using a stack.

## Concepts Practiced

- Stack operations and LIFO behavior
- Array-based stack implementation
- Overflow and underflow handling
- Practical use of stacks in string processing and expression validation
