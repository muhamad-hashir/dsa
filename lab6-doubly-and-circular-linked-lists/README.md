# Weekly Study: Doubly and Circular Linked Lists

This folder contains our weekly study work on **doubly linked lists** and **circular linked lists**.

## What We Did

- Created nodes for linked lists.
- Added items at the front and end of a doubly linked list.
- Deleted items from the head and tail.
- Displayed a doubly linked list forward and backward.
- Used `next` and `prev` pointers.
- Made a book list using a doubly linked list.
- Searched for books by ISBN.
- Found the most expensive book.
- Created a circular linked list.
- Added items at the beginning, end, and after a value.
- Deleted items from a circular linked list.
- Displayed a circular list by stopping when it reached the head again.

## Main Topics

- Doubly linked lists
- Circular linked lists

- Node deletion
- Forward and backward traversal
- Searching
